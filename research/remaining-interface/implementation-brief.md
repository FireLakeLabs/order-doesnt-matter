# Remaining interface / editor proposals

Research package E0, based on main `67e6b7f`. No production implementation,
retention changes, guided tour, dependencies or hosting changes. Open
[mockup.html](mockup.html) directly; all behavior is simulated. The parent can
pass its absolute path to `html_preview`, then `html_render`. Phone mode caps the
study at 390px; use an actual 390px viewport for fit verification.

## Direction and order

Keep the score and one in-page editor. Now/Watch describe playback; editing can
stay pinned elsewhere. Planet and List enter the instrument editor, then navigate
inside that same shell. Preserve the initiating DOM control across navigation;
Done/Escape returns there, including an enlarged List. Enlargement reparents the
existing view and returns focus to its initiating enlarge button. Escape inside
an editor closes that editor first; elsewhere an enlargement closes first.
Do not add a second editable surface to Now.

Conservative defaults: Ring, full-name List on dense phones, no camera travel
with reduced motion, no new system inset. The owner selected **Paper** as the theme picker’s default on 2026-11-14;
Fern and Night remain available choices.
Numbered drawing identifiers supplement full names; they are not persisted IDs.
Room labels are engine orbit numbers with derived descriptions, not new editable
room names. Solid/dashed outlines plus text distinguish membership without colour
alone. Never draw settings as a processing chain or claim a room conflict winner.

## Mini forms: practical scope and semantic checks

Use `src/import/mini.ts`, `src/document/types.ts`,
`src/document/edits/step-shared.ts`, `rhythm-{layout,marks,pulses,speed,euclid}.ts`,
`values-{chunk,modifier,group}.ts` (last two groups under `src/document/edits/`),
`src/editor/kinds/{rhythm,values}.ts` and their CSS. These are current paths;
new operations should remain one file per edit. Do not expand `isGroup` blindly:
polymeter/choice have different timing, traversal and permitted operations.

| Form                                             | UI extension                                                                                                                           | Required real-Strudel checks                                                                                                                                                                                       |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Polymeter `{fs2 a2 cs3,e3 ~}%4`                  | Simulated representative: lane/part List, explicit per-cycle value; reuse value fields; queried note strip. Never equal-width “steps”. | Print/parse preserves lane lengths and `%`; edits affect selected lane only; compare starts/values across negative, fractional and later cycle windows; `%` patterned/unknown keeps source.                        |
| Choice `fs2 \| a2 \| cs3`                        | Ordered candidate List with add/remove/value; label deterministic by time, not a probability slider or simultaneous notes.             | Unchanged round trip preserves time-addressed choices; query the same absolute window twice, later windows, nested choice/rest. Editing candidates may change choices; no fixed time slot is promised.             |
| Patterned speed `fs2*<1 2>` / `/`                | Rate subtree with constant/sequence/source mode; reuse values UI, keep independent source fallback.                                    | Rates change by cycle; preserve rate direction, nesting, weights and token order; malformed, zero/nonfinite cases refuse without replacing last doc. Existing `speedRhythm` accepts literal positive numbers only. |
| Patterned Euclid `fs2(<2 3>,8,<0 1>)`            | Hits/steps/rotation each a pattern-capable field; notes queried, no fixed pulses when unproven.                                        | Actual starts across changed turns, rotations, rests, patterned steps; failed query explicit. `euclidNumbers` currently accepts bounded literal integers only.                                                     |
| Repeated outer marks `fs2*2*3`, `/`, mixed `!/@` | Ordered mark rows with one selected occurrence, never collapse to one factor or sort operations.                                       | Parse/print exact effective sequence; edit only occurrence, weight/repeat/chance order and random seed preserved. `rhythmMarks` currently rejects duplicate mark names.                                            |
| Negative hits `fs2(-3,8)`                        | Signed hits field with plain explanation only after pinned-engine canary establishes complement behavior.                              | Verify actual complement/rotation semantics, zero/extremes and signed patterned hits; preserve source for unproven combinations. Do not relax `euclidNumbers` guard without evidence.                              |

Callback extensions must distinguish argument pattern from callback, bind the
actual callback parameter, and retain hole-rooted transforms, lexical references,
settings, opaque layers and nested order. `every`, `off`, `jux`, `sometimes`,
`when`, `superimpose`, `layer` need separate arity/branch canaries before controls
are enabled. Use `context.ask` and existing stale-request cancellation for queried
comparisons; identical notes in one window do not prove transformations commute.

## Questions for the owner (parent presents with the mockup)

- **Required before an ambitious new system display:** what job should it do
  beyond instrument context? Recommendation: omit it, so this need not block work.
- **Resolved preference:** the owner selected Paper as the default; Fern and Night remain available.
- **Optional preference:** keep a Watch-only fly-through study? Recommendation:
  retain as optional later, Ring default; static depth with reduced motion. No
  WebGL/library adoption is proposed. Actual motion readability is untested.
- **Optional preference:** first four List rows plus “10 more”, or all rows?
  Recommendation: four plus explicit total, with disclosure/focus state retained.

No required unanswered decision blocks navigation, multi-room data, source label
repair or structural List-first mini work. Proposals still need parent/owner
review before production UI work; this package does not start it.
