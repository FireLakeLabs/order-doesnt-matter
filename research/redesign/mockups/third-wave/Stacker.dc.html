Shows

Every bar is a score-shaped piece. New material stays in the well; an exact repeat flashes its earlier bar number and clears.

Mapping

  • bar → piece; each part → thin row at real note spans
  • bar progress → fall; bar line → lock or clear
  • all relative notes + values equal → repeat flash
  • different settings → new piece, even with same rhythm
  • sections → well labels; dense notes → counted patches

Build

  • Canvas 2D · score/whole song
  • no changes · effort large
  • prefix at now → stack; no game state
  • risk: few exact repeats with signals
