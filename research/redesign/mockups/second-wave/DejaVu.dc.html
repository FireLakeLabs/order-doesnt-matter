Shows

In Strudel every cycle can differ. This bar is drawn over the one before, so you see exactly what alternation, randomness and signals changed.

Mapping

  • this bar → solid; the bar before → dashed, same place in its cycle
  • new note → sparkles · vanished note → stays as a dashed ghost
  • changed pitch or setting → old → new on the note
  • top strip → every bar, brightness = how much it changed
  • compare with the previous bar, or this bar last time through

Build

  • Canvas 2D · score · whole song
  • notes matched by instrument, start and pitch
  • unasked bars in the strip → hatched, never dark
