Pitch as a place. Every pitch the piece uses is a string; a note plucks its string and it shimmers for exactly as long as the note lasts.

  • gain → shimmer width · instrument → its colour
  • strings this section uses stand bright; the rest recede
  • unpitched instruments → drumheads on the base
