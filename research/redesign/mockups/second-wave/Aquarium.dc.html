Shows

Rooms are shared and unruly. Each room is a tank; whoever sends into it swims there, and a note that changes the room stirs it for everyone.

Mapping

  • room (orbit) → a tank; instruments sending into it → its fish
  • onset → bubbles; a larger send lets out more
  • a note setting size or feedback → the tank stirs; the banner names it
  • two notes disagreeing about a room → the banner says contested
  • no send → the dry bowl

Build

  • Canvas 2D · score · window
  • tanks from frame.rooms; sends from note values
  • over 6 rooms → tanks shrink into a shelf
