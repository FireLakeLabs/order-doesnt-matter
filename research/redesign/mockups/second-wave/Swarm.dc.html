Swarm

shooter
bar 11 · 40%

Shows

A fixed shooter where every note is an enemy. The ship rides the playhead and destroys each one exactly on its onset; held notes are carriers.

Mapping

  • instrument → a formation row · place in the cycle → column
  • ship → the playhead, sweeping the bar left to right
  • onset → that enemy is hit; notes due in the next eighth dive first
  • held note → a carrier as long as the note, burning away as it plays
  • section → a new named wave · gain → enemy size

Build

  • Canvas 2D · score · window
  • played slots warp in faintly for the next bar
  • crowded rows → one shielded swarm bar
