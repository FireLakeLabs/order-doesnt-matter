Shows

The project's name, made literal. Every note walks out wearing its settings. Put them on in any order and the outfit is the same.

Mapping

  • note → a figure that reaches the front at its onset, poses while it holds
  • each setting in use → one garment: cutoff a hat, room a cape, shape spikes
  • value → garment size; a moving value changes it note to note
  • gain → figure size · pan → the side of the runway it walks
  • the posing note's tag lists its whole bag of settings

Build

  • Canvas 2D · score · window
  • settings with no garment yet → a plain badge
  • crowds → merge into one figure with a count
