Shows

The song as a quilt: a row per section, a patch per bar. Bars that repeat sew identical patches, so the song's form shows up as pattern.

Mapping

  • section → a row · cycle → a patch, in order
  • instrument → a square ring, outermost first; time runs clockwise
  • note → a stitched stretch of its ring at its real place; onset → a knot
  • note carried over from an earlier cycle → dotted, no knot
  • played → sewn in colour · ahead → chalk

Build

  • Canvas 2D · score · whole song
  • long sections → rows wrap
  • over 8 instruments → inner rings blend to texture
