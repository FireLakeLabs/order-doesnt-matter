Shows

Kinetic type. Instrument names set as a giant poster: each word punches at its onsets, stays solid while a note holds and goes hollow at rest.

Mapping

  • instrument → its name on one line, in row order
  • onset → the word punches · held note → solid, stretching as it holds
  • gain → weight · resting → outline only
  • moving setting → the word's slant, reset at each onset
  • section change → the poster resets under the section's name

Build

  • Canvas 2D, theme display font · score · window
  • 20 instruments → two columns, smaller type
  • Pocket theme → weight and outline only
