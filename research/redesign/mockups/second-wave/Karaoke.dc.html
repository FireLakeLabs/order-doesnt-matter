Shows

The score as lyrics. Each note is a word set where it starts; the colour sweeps through as it sounds and a ball hops onto every onset.

Mapping

  • note → its sound name or pitch, set at its real start
  • underline → the note's real length
  • sounding → the colour wipes through the word
  • onset → a ball lands; hop height is the gap to the next
  • gain → word size · section name → the verse title

Build

  • Canvas 2D · score · window
  • one cycle per line; the next line waits below
  • crowded line → words shrink to dots
